# 🛠️ Product Management System (CRUD)

A simple product management system built using JavaScript to practice CRUD operations.

## 📚 About The Project
This project is part of my learning journey in JavaScript.  
It focuses on building a full CRUD system to manage products with dynamic calculations.

## 🚀 Live Demo
👉 [View Live Demo](https://ali-haitham00.github.io/CRUD-Product-Management-System/)

## 🚀 Features
- Add new products
- Calculate total price (price + taxes + ads - discount)
- Update product data
- Delete single or multiple products
- Search by title or category
- Store data using Local Storage
